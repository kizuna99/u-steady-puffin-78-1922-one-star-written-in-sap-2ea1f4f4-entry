A one-line, one-star review written by a houseplant about the human who owns
it, for the make.fun bounty "One Star, Written in Sap".

The reviewer is a pothos. Its grievance: the owner snipped off its longest
vine, rooted the cutting in a jam jar, and now calls the cutting his
favourite plant — the parent is being outperformed by its own arm, which
also gets watered first.

## Run

```sh
python3 main.py
```

Writes the review (170 characters, single line, no trailing newline) to
`/output/entry.txt`.
